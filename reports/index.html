Why CPU looked faster

It is a small overhead gap, not a faster class of machine. On test-clean the server itself spent 99.6 s on CPU and 105.4 s on GPU1. Median call: 29.1 ms versus 32.8 ms. Both are about 0.005× realtime. The 58 MB Tiny model is already cheap on a 9950X. These clips are short — median 5.8 s, max 35 s — so HIP launch and copy cost more than the matmul saves. audio.cpp’s GPU path is a CUDA-shaped port. GPU1 was also holding Ali TTS in the same process. That can add noise; it does not explain a different accuracy regime.
